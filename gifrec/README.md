# gifrec

輕量、可攜的螢幕錄影轉 GIF 工具，附簡易編輯器。用 Rust + egui 寫成，不需要 WebView2。

## 下載

不用安裝。每次推送 `gifrec/` 的變更後，GitHub Actions 會自動編譯：

1. 打開本 repo 的 **Actions** 頁 → 左側 **gifrec** → 最新一次執行
2. 下方 **Artifacts** 下載 `gifrec-windows`，解壓縮
3. 雙擊 `gifrec-gui.exe`（`gifrec.exe` 必須放在同一個資料夾）

## 錄影

- 錄影範圍：全螢幕，或拖曳框選區域（單擊 = 整個螢幕，Esc / 右鍵取消）
- 開始方式：倒數幾秒，或按熱鍵才開始
- 全域熱鍵（預設 **Ctrl+Shift+F9**）：待命時按一下開始，錄影中按一下停止
- 錄影時設定視窗會自動縮小，不會被錄進去
- 畫面完全沒變的影格會跳過，GIF 只記錄有變動的區域，檔案較小

## 編輯

錄完按「編輯這個 GIF」，或把 GIF / `.gifrec` 專案拖進視窗、拖到 `gifrec-gui.exe` 圖示上。

**工具**（右側面板或按字母鍵切換）

| 工具 | 鍵 | 用法 |
|---|---|---|
| 選取 | V | 點選、拖曳移動、拉八個控制點縮放；雙擊文字直接改內容 |
| 馬賽克 | M | 在畫面上拖曳框出範圍（單擊放預設大小），可調格子大小 |
| 模糊 | B | 同上，可調模糊程度；馬賽克 / 模糊可互換 |
| 文字 | T | 點一下放文字；多行、字級、顏色、半透明黑底；拉角落改字級 |
| 拉近 | Z | 框出要放大的範圍，這段影格會平滑拉近、再拉遠 |
| 裁切 | C | 拖曳框出要保留的畫面，拉控制點微調（Shift 鎖比例） |

另外可加入圖片（PNG / JPG，可直接拖進視窗），維持比例縮放、調不透明度。

**時間軸**：下方是影格縮圖，點或拖過去就能跳格；每個效果有一條色條代表出現範圍，
拖兩端改起訖、拖中間整段移動。也可以設定頭尾裁剪、播放預覽。

**畫面**：裁切範圍、輸出寬度（像素或百分比）。上方切到「輸出預覽」可以看套用裁切、拉近、縮放後的實際樣子。

**專案**：Ctrl+S 存成 `.gifrec` 專案（圖片內嵌在檔案裡），之後可以回來繼續改。來源 GIF 放在專案檔旁邊即可。

**快捷鍵**

| 按鍵 | 功能 |
|---|---|
| Ctrl+Z / Ctrl+Y | 復原 / 重做（拖曳一次算一步） |
| Ctrl+C / Ctrl+V / Ctrl+X | 複製 / 貼上 / 剪下效果 |
| Ctrl+D | 複製一份選取的效果 |
| Delete | 刪除選取的效果 |
| 方向鍵 | 微調位置 1 px（Shift = 10 px）；沒選取時為前後一格 |
| 空白鍵 | 播放 / 暫停 |
| , / . 、Home / End | 前後一格、跳到頭尾 |
| Ctrl+S / Ctrl+Shift+S | 儲存 / 另存專案 |
| Esc | 回到選取工具、取消選取 |

匯出成新檔，不會覆蓋原始檔。

## 命令列

```
gifrec                              全螢幕（主螢幕）
gifrec --select --wait              框選後待命，按熱鍵開始
gifrec --region 100,200,800,600     指定區域 x,y,寬,高
gifrec --list                       列出螢幕
gifrec --help                       所有參數
```

## 自己編譯

```
cd gifrec
cargo build --release
```
